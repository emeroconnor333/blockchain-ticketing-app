Summary

A Web3 Distributed Application (DApp) that implements simple ticketing system.

Code Overview

The frontend is built with HTML, CSS, and JavaScript split into modules:

  • config.js: RPC endpoint, contract address, vendor address, ticket price, ABI
  • wallet.js: generates a new Ethereum keypair and keystore JSON file
  • balances.js: reads SETH and ticket token balances from the Sepolia network for any address
  • transactions.js: signs and sends the buyToken() and transfer() contract calls
  • addressBook.js: saves and retrieves labelled wallet addresses in localStorage
  • ui.js: tab switching, modal, clipboard copy, and keystore decryption helpers
  • app.js: wires all DOM events to the above modules

The smart contract EmerTicket.sol implements the ERC-20 standard with a buyToken() payable function that accepts SETH, transfers the corresponding ticket tokens to the buyer, and forwards the SETH to the vendor.

Design Description

Features are split between a number of tabs.

  • Create Wallet: generate a keypair client-side using web3.js
  • Check Balances: check any address's SETH balance and optionally add a locally saved label to frequently used addresses
  • Buy a Ticket: use SETH to buy a ticket from the vendor
  • Return Ticket: return your ticket to the vendor

The contract owner (vendor) receives all SETH payments and holds the initial ticket supply.

About the Keystore Format

  • version — Keystore spec version (3).
  • id — UUID for this wallet.
  • address — Public Ethereum address derived from the private key.
  • crypto.ciphertext — AES-128-CTR encrypted private key.
  • crypto.kdf — scrypt key-derivation function used to derive an encryption key from your password.
  • crypto.mac — Message authentication code to verify the password on decryption.
